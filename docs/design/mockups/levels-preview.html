A small walker/faller/skill simulation (D7 numbers) checks each level twice: with no skills (at the level's RR and at RR 99) nobody may reach the required count, and with the intended solution enough mumbles must get home with every surviving landing ≤ 48 px (spawn ≤ 40 px) and the last one home within half the time limit. window.runChecks() returns the same results as JSON.
