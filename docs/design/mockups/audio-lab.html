Mumblemarch · Audio lab

Every sound effect recipe from docs/design/parts/audio-copy.md, implemented with the SfxRecipe signature of src/audio/sfx.ts: (ctx, out, when, pitch) => void. Only voice chirps and builder-low read pitch; the others ignore it, so they also run as (ctx, out, when). Console: await measureAll() / await checkMusic() return JSON. Nothing plays until you click. Measure all renders each recipe offline (44.1 kHz, 2 s, unity bus gain) and reports duration-to-silence (−60 dBFS), peak and loudness.
